# ⏰ Real-Time Digital Clock

A responsive digital clock web application that displays real-time hours, minutes, and seconds using JavaScript.

## 🚀 Features
- 🕒 Live time updates (HH:MM:SS)
- 📅 Displays current date
- 📱 Responsive design
- 🎨 Modern UI

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
